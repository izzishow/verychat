Google 로그인 설정 안내

ℹ️ Google OAuth 환경변수(Client ID / Client Secret) 등록이 필요합니다.
1

Google Cloud Console 접속 및 프로젝트 생성

Google Cloud Console (API 및 서비스)에 로그인하고 상단에서 새 프로젝트를 생성합니다.

2

OAuth 동의 화면 구성

[OAuth 동의 화면] 메뉴에서 User Type을 외부(External)로 선택 후 앱 이름과 지원 이메일을 입력합니다.

3

OAuth 클라이언트 ID 발급 & 승인된 리디렉션 URI 등록

[사용자 인증 정보] > [+ 사용자 인증 정보 만들기] > [OAuth 클라이언트 ID] 선택 (유형: 웹 애플리케이션) 후 아래 URI를 [승인된 리디렉션 URI]에 추가합니다:

4

VeryCloud 환경변수 등록

발급받은 GOOGLE_CLIENT_ID와 GOOGLE_CLIENT_SECRET을 VeryCloud 환경변수에 등록하면 실제 Google 로그인이 즉시 작동합니다.
